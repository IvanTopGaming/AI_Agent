# Дизайн-документ: Интерфейс создания обращения и чата с AI-ассистентом поддержки

## 1. Введение и цель проекта
Создание современного минималистичного пользовательского веб-интерфейса в эстетике Linear и Claude для службы технической поддержки (Helpdesk / Support). 
Интерфейс включает:
1. Экран/окно составления первичного обращения (Ticket Composer).
2. Бесшовный анимированный переход в активный чат с искусственным интеллектом (AI Chat View).
3. Интерактивный диалог с симуляцией стриминга ответов нейросети, форматированием кода и метаданными тикета.
4. Поддержку светлой и темной тем оформления.
5. Интерактивное отображение изменений в реальном времени через локальный dev-сервер Vite (HMR).

---

## 2. Архитектура и стек технологий
* **Фреймворк:** React 19 / TypeScript / Vite
* **Стилизация:** Tailwind CSS (с поддержкой `class: "dark"`, кастомными палитрами Slate/Zinc/Indigo)
* **Анимации:** Framer Motion (для плавного морфинга карточки обращения в чат и появления сообщений)
* **Иконки:** Lucide React
* **Рендеринг текста/Markdown:** кастомные компоненты с подсветкой кода и кнопками копирования
* **Стейт-менеджмент:** React useState / useReducer (чистое клиентское состояние без лишнего оверхеда)

## 3. Пользовательский флоу (User Journey)

### Этап 1: Экран составления обращения (Ticket Composer)
1. Пользователь видит сфокусированный интерфейс создания обращения:
   * **Тема обращения** (краткий заголовок с быстрыми чипсами подсказок: "Не работает API", "Проблема с авторизацией", "Сбой биллинга").
   * **Категория**: Техническая проблема, Вопрос по оплате, Ошибка в приложении, Другое.
   * **Приоритет**: Низкий (Low), Средний (Medium), Высокий (High), Критический (Urgent) со стилизованными индикаторами.
   * **Текст обращения**: многострочное расширяемое текстовое поле с плейсхолдером и счетчиком символов.
   * **Прикрепление файлов**: зона загрузки скриншотов/логов с визуализацией прикрепленных бейджей.
   * **Кнопка отправки**: «Отправить в AI-поддержку» (горячая клавиша `Ctrl+Enter` / `Cmd+Enter`).
2. При валидации форма проверяет заполнение обязательных полей (тема, текст).

### Этап 2: Анимация перехода
1. При нажатии «Отправить» карточка плавно трансформируется: форма сворачивается в компактный заголовок тикета (`#TK-8492`), открывая пространство для ленты сообщений.
2. Содержимое обращения становится первым сообщением пользователя с меткой даты, приоритета и категории.

### Этап 3: Активный чат с нейросетью
1. AI немедленно начинает генерировать персонализированный ответ (индикатор печати -> пословный стриминг текста).
2. Ответ нейросети содержит:
   * Анализ проблемы на основе категории и приоритета.
   * Рекомендации по шагам (с форматированием Markdown, списками и сниппетами кода при необходимости).
   * Быстрые кнопки обратной связи: «Решение помогло», «Уточнить деталь», «Вызвать оператора-человека».
3. Нижняя панель чата позволяет пользователю продолжить диалог: вводить новые вопросы, отправлять уточнения и прикреплять файлы.
4. В шапке чата всегда доступна кнопка «Детали обращения» (для просмотра исходного тикета) и кнопка «+ Новое обращение» для сброса и создания новой заявки.

## 4. Дизайн-система (Linear & Claude Inspired)

### Цветовая палитра:
* **Dark Mode (основной/по умолчанию):**
  * Фон страницы: `#0B0C10`
  * Контейнеры/карточки: `#161722`
  * Второстепенные элементы/инпуты: `#1E202E`
  * Границы: `rgba(255, 255, 255, 0.08)`
  * Текст: основной `#F3F4F6`, второстепенный `#9CA3AF`, приглушенный `#6B7280`
  * Акцент: Indigo `#6366F1` (hover `#4F46E5`), Emerald `#10B981` (успех/статус онлайн)
* **Light Mode:**
  * Фон страницы: `#F8FAFC`
  * Контейнеры/карточки: `#FFFFFF`
  * Второстепенные элементы/инпуты: `#F1F5F9`
  * Границы: `#E2E8F0`
  * Текст: основной `#0F172A`, второстепенный `#475569`
  * Акцент: Indigo `#4F46E5`

### Типографика:
* Гарнитура: Inter, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif.
* Моноширинный шрифт: ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas.

## 6. Тестирование и верификация
1. Проверка сборки `npm run build` (TypeScript + Vite).
2. Проверка валидации формы обращения (пустая тема/текст блокируют отправку с подсказкой).
3. Проверка переключения темной и светлой темы.
4. Проверка адаптивности (десктоп и мобильный экран).
5. Проверка генерации ответа AI и добавления последующих сообщений в чат.
6. Проверка кнопки сброса («Новое обращение»).
